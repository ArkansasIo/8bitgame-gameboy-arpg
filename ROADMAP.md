# ARPG GB QUEST roadmap

Design spec: the owner's *RPG/MMORPG Framework Template v1.1* (10 attributes, accuracy/evasion,
armor mitigation by attacker level, buff/debuff catalog, 11 equipment slots, 6 rarity tiers).
Everything ships as original content. No Middle-earth, WoW, Diablo, Elden Ring or
Throne and Liberty names, maps or assets.

## Done
- [x] v0.1-0.3: window menus, GBC color, 16-room world, 5 biomes + town, classes, spells,
      inventory, shop, inn, quests, save
- [x] v0.4.0: levels 1-720, attributes + sub-stats, scaling monsters, MP, rename to ARPG GB QUEST
- [x] v0.4.1: 5 save slots, load screen, loading screen, boot logo (ARKANSASIO)

## Next phases
1. **Framework stats (v0.5):** 10 attributes (STR DEX CON INT WIS VIT SPI LCK WIL CHA),
   accuracy/evasion hit chance, armor/resist mitigation, crit chance/damage/resistance,
   tenacity, CDR, haste, penetration, regen
2. **Buff/debuff engine (v0.5):** power, haste, shield, fortify, regen, stealth / stun, slow,
   weakness, frailty, burn, poison, bleed, frostbite. Duration, stacking, refresh, dispel
3. **Character creation (v0.6):** 9 races x 18 classes (base sprites + palettes, racial bonuses)
4. **Gear (v0.6):** 11 slots, 6 rarities (Common to Mythic), item level + power level,
   ~420 generated weapons/armor/accessories, set gear with 2/4/6-piece bonuses,
   rings/talismans, smith upgrades +1 to +10, random affixes
5. **Professions (v0.7):** gathering (mining, herbalism, skinning, fishing) and crafting
   (smithing, alchemy, tailoring, cooking) with skill levels
6. **World (v0.8):** original continent map, kingdoms, cities, towns, NPCs, outdoor and
   underground zones/biomes
7. **Endgame (v0.9):** dungeon finder with 90 instances (dungeons, raids, trials), a 100-floor
   tower, 420-monster roster, bosses and arch-bosses
8. **Presentation (v1.0):** more detailed graphics, 42 music tracks + sound effects
